Python新增probe_profit_alert_sources.py，只调用国内和国际来源接口：

1. 获取数据日前60天至当日（含首尾，共61日）的国内历史与当日明细；保存原始分页元信息。
2. 复用既有历史构建和当日事实校验，核对同日企业利润一致。
3. 获取国际完整日回执，执行既有来源/日期/身份/金额校验；重复获取并核对回执摘要一致。
4. 保存来源证据及source-probe-report.json，不执行卡片投递。

## 真实环境入口

在利润项目根目录执行，先由安全配置机制注入PROFIT_API_URL、PROFIT_API_KEY、PROFIT_API_SECRET：

```sh
python3 -m scripts.probe_profit_alert_sources --data-day 2026-11-26 --output-dir /授权持久目录/b2-source-check-001
```

输出目录必须尚不存在，避免覆盖证据。日期必须为上海已结束自然日；该入口无发送操作，但可能让服务端产生合法来源查询与冻结回执，须有来源授权。含客户事实的输出只存授权位置，不提交GitHub。

## 静态核对与真实联调门槛

| 项目 | 事实及下一步 |
|---|---|
| BI接口 | CustomerProfitReportService.query(QueryParams)与当前泛化调用的接口名/方法名对应；真实序列化和PageResponse形状仍须实测 |
| 日期 | BI查询buildQuery使用ge(startTime)、lt(endTime)；适配器将结束日期转换为次日上海00:00 |

| 国际 | 公司MCP权限、指定工具、逐日预算及原始回执证据需要A提供 |
