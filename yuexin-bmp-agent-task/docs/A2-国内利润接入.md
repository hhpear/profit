# A2 国内利润接入记录

2026-11-27。仅修改 agent-task 的来源适配；不涉及 A1 身份配置，不修改 BI/Notice。

## 已落实的实现

- 调用 `com.yuexin.bmp.bi.service.CustomerProfitReportService.query(QueryParams)`；支持注册中心配置与受控 Dubbo 直连配置 `profit.source.dubbo-url`，直连地址只由服务端管理。
- 查询固定 cycle=Day、source=Detail、marketIndex=false；日期使用上海时间半开区间 [startDate 00:00, endDate次日 00:00)。
- BI 的 query(page=null) 源码采用单次 selectList。本次改为单次完整读取，拒绝将无法保证排序的上游分页结果拼接成完整回执。
- 校验 totalCount 与返回长度相等，校验唯一事实 ID、授权 customerId、日期、企业编码/名称、金额；按源 ID 稳定排序后冻结，在 task 本地回执上分页。
- 默认最大接收 100000 行，可用 profit.source.max-domestic-rows 配置。该限制发生在完整响应接收后，并非上游内存或响应体大小限制；需在联调确定真实范围和资源容量后使用。
- 不同请求口径不能复用同一 queryId。冻结回执保留期沿用现有七天。

## 字段与范围

| Python 字段 | BI 来源 | 状态 |
|---|---|---|
| timeStr | time 转 Asia/Shanghai 日期 | 代码与日期边界测试完成 |
| entCode | entCode | 校验非空，保留稳定编码 |
| entName | 服务端 enterpriseNames 配置 | 授权主数据待配置 |
| smsIncome | smsIncome 含税金额 | 需同输入对账 |
| smsProfit | smsOperateProfit 含税运营利润 | 仅为候选映射，等价性待核对 |
| customerTypes | 由 customerIds 落实指定客户类型集合 | 名单与维护方式待业务/主数据确认 |

profit.source.mapping-confirmed 和 stable-read-confirmed 默认不开放。单次读取避免了多次分页拼接，但并不证明数据库读取窗口、口径和名单已经确认；不能为绕过检查而将开关直接设为 true。
