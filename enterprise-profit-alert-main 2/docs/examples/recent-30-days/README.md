## 脱敏和样例用途

不上传客户名称、企业/账号编码、真实金额、原始利润走势、邮箱、open_id、message_id、chat_id、个人目录或认证材料。仅保留每日汇总数量、规则版本、异常类型统计及状态。异常与零告警的结构化样例见本目录两个 decision-example 文件。

样例用于解释流程期望；不含利润计算输入，不可用于复算算法或做新旧逐企业对账。后续研发应在授权环境获取历史输入，另用合成数据覆盖阈值和连续下降测试。零告警日不应伪造一张已发送卡片。

异常卡片内容的脱敏摘录见 [anomaly-card-excerpt.md](anomaly-card-excerpt.md)；零告警不发送业务卡片，预期见 [zero-decision-example.json](zero-decision-example.json)。
