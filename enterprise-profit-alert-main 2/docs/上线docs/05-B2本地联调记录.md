## 修复保留方式

旧 Notice 的 readback 在首次 VERIFIED 时返回 senderAppId/contentMatch，但重复回读只返回账本通用字段，Python 因此拒绝恢复。修复为重复回读补齐 senderAppId 与 EXACT，并增加重复回读测试。

根据用户保留删除的决定，该修复没有恢复到源文件，已保存为enterprise-profit-alert-main 2/tools/notice-b2-readback-reference.patch，仅供新服务端设计参考，不自动应用。enterprise-profit-alert-main 2/tools/verify_notice_b2.py 保留隔离验证方法，依赖的旧源文件已删除，当前不能直接运行；须等新方案明确后改造。
